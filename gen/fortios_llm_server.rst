fortios_llm_server -- Configure LLM Proxy servers in Fortinet's FortiOS and FortiGate.
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

.. versionadded:: 2.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- This module is able to configure a FortiGate or FortiOS (FOS) device by allowing the user to set and modify llm feature and server category. Examples include all parameters and values need to be adjusted to datasources before usage. Tested with FOS v6.0.0



Requirements
------------
The below requirements are needed on the host that executes this module.

- ansible>=2.16


Tips
----
Using member operation to add an element to an existing object.

FortiOS Version Compatibility
-----------------------------
Supported Version Ranges: v8.0.0

Examples
--------

.. code-block:: yaml+jinja
    
    - name: Configure LLM Proxy servers.
      fortinet.fortios.fortios_llm_server:
          vdom: "{{ vdom }}"
          state: "present"
          access_token: "<your_own_value>"
          llm_server:
              accept_custom_model: "enable"
              anthropic_version: "<your_own_value>"
              api_key: "<your_own_value>"
              azure_api_version: "<your_own_value>"
              azure_resource_name: "<your_own_value>"
              built_in_server: "openai"
              chat_completions_api: "none"
              custom_model_allow_regex: "<your_own_value>"
              custom_model_block_regex: "<your_own_value>"
              display_name: "<your_own_value>"
              end_point: "<your_own_value>"
              image_gen_api: "none"
              models: "<your_own_value>"
              name: "default_name_16"
              type: "built-in"
              verify_cert: "enable"
